### Sobre mí

Soy estudiante de la **Tecnicatura Universitaria en Programación en UTN FRT**, en Tucumán, Argentina.

Me interesa el desarrollo de software, especialmente el backend con **C# y .NET**, y la creación de aplicaciones que resuelvan problemas reales.

También me apasiona explorar el mundo de la **ciberseguridad y las redes**: entender cómo se comunican los sistemas, cómo funcionan los protocolos y cómo proteger aplicaciones, servicios e información.

Actualmente estoy construyendo proyectos propios mientras profundizo mis conocimientos en Linux, Docker, redes y seguridad informática.

- 💻 Backend Development — C# / ASP.NET Core
- 🔐 Cybersecurity — Application Security
- 🌐 Networking — TCP/IP & Network Fundamentals
- 🐧 Linux — System Administration
- ☁️ DevOps & Cloud — Docker / Azure
