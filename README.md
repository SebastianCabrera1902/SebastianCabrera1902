## Sobre mí

Soy estudiante de la **Tecnicatura Universitaria en Programación en UTN FRT**, en Tucumán, Argentina.

Me interesa el desarrollo backend, especialmente con **C# y ASP.NET Core**, y la construcción de aplicaciones que resuelvan problemas reales.

Actualmente trabajo en proyectos que me permiten aprender sobre diseño de APIs REST, bases de datos, autenticación, gestión de usuarios y reglas de negocio.

También estoy ampliando mis conocimientos en Docker, Azure y prácticas de DevOps, con el objetivo de comprender mejor el ciclo completo de desarrollo y despliegue de software.

## Proyectos destacados

### UTN Conecta
<a href="https://github.com/SebastianCabrera1902/utn-conecta">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=SebastianCabrera1902&repo=utn-conecta&theme=tokyonight" />
</a>

Aplicación orientada a conectar graduados de la UTN con oportunidades laborales, pasantías y propuestas de formación.

**Tecnologías:** ASP.NET Core, .NET 10, PostgreSQL, Entity Framework Core, JWT y React Native.

**Características principales:**
- API REST con autenticación y autorización.
- Gestión de graduados y organizaciones.
- Administración de oportunidades.
- Control de acceso según roles.
- Validaciones y pruebas de endpoints con Postman.

[Ver repositorio](https://github.com/SebastianCabrera1902/utn-conecta)
